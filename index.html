🔧 Configuração — apenas 2 passos

Você vai criar um espaço gratuito no JSONBin.io para guardar suas anotações na nuvem. Leva menos de 2 minutos.

1
Acesse jsonbin.io → clique em Sign Up → crie conta com seu email.
Após entrar, clique no botão NEW BIN → deixe o conteúdo como {} → clique em Create Bin.
Copie o BIN ID que aparece na URL: https://api.jsonbin.io/v3/b/ESTE_TRECHO
2
Ainda no JSONBin, clique no seu nome (canto superior direito) → API Keys → copie a Master Key.
