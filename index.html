⚙️ Configurar Envio de Emails

📋 Passo 1 — Criar o Formulário (a partir da planilha já criada)

1. Abra a planilha relay: Meu Caderno — Email Relay ↗
2. No menu superior clique em Ferramentas → Criar formulário — uma nova aba abrirá com o formulário vinculado
3. Na pergunta padrão, mude o tipo de Resposta curta para Parágrafo e coloque o título dados
4. Clique em ⋮ (canto superior direito do form) → "Obter link pré-preenchido"
5. Digite qualquer texto → clique "Obter link"
6. Copie a URL gerada — extraia o número entre entry. e =
   Exemplo: …?entry.1234567890=texto… → o ID é 1234567890
⚙️ Passo 2 — Adicionar o script na planilha relay

1. Volte para a planilha Meu Caderno — Email Relay ↗
2. Clique em Extensões → Apps Script
3. Apague tudo e cole o script abaixo → Ctrl+S para salvar
4. Clique no ícone de relógio ⏱ (Acionadores) → "Adicionar acionador"
5. Configure: Função: onFormSubmit · Origem: Do Spreadsheet · Tipo: No envio do formulário
6. Clique Salvar → autorize com seu email Meli quando solicitado
🔗 Passo 3 — Conectar ao Meu Caderno

Cole a URL do formulário (aba que abriu no Passo 1 — ex: …/forms/d/1BxiMV…/viewform)
e o ID do campo copiado no Passo 1 (apenas os números, ex: 1234567890)
