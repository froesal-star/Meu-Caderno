🔧 Conectar ao GitHub — 1 passo só

O caderno salva seus dados diretamente no seu repositório GitHub. Configure uma vez e acesse de qualquer dispositivo.

1
No GitHub clique na sua foto → Settings → role até o fim → Developer settings → Personal access tokens → Tokens (classic)

→ Generate new token (classic) → em Note escreva Meu Caderno → Expiration: No expiration → marque repo → Generate token

→ Copie o token gerado (começa com ghp_) — ele só aparece uma vez!

⚠️ Seu repositório é público — qualquer pessoa pode ler o arquivo de dados se souber o endereço. Para uso com informações sensíveis, considere tornar o repositório privado.
